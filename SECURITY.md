# Security Policy

## Supported Versions

We issue security updates for the following releases:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within ECF, please send an email to our core security team at `security@ecf.dev`. All security vulnerabilities will be promptly acknowledged and addressed.

Please include:
1. Description of the issue and potential impact.
2. Steps to reproduce or proof-of-concept script.
3. Suggested fix (if applicable).

We ask that you do not publicly disclose the issue until we have had an opportunity to address it.
